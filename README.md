# MealMate

MealMate is an AI-assisted meal planning and grocery shopping project. It helps households plan a home-cooked meal from their budget, serving size, food preferences and dietary constraints, then prepare a verifiable grocery cart.

**Status:** discovery and design. No application or checkout is implemented yet.

Development follows a business-first, design-first process. See `AGENTS.md` and `docs/PRODUCT.md` once the bootstrap pull request has been reviewed and merged.
